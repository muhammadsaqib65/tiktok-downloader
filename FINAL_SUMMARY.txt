================================================================================
🔌 API ENDPOINTS
================================================================================

POST /api/download
  Purpose: Download TikTok video without watermark
  Input:   { "url": "https://tiktok.com/@user/video/123" }
  Output:  Video data (downloadUrl, hdDownloadUrl, title, author, etc.)

GET /api/download
  Purpose: Get download history from database
  Output:  Array of download records

GET /api/health
  Purpose: Health check
  Output:  { "ok": true }

================================================================================
🗄️ DATABASE
================================================================================

Table: downloads
  ├── id (serial, primary key)
  ├── video_url (text, not null)
  ├── video_title (text)
  ├── author (text)
  └── downloaded_at (timestamp, default now)

Purpose: Track download history and analytics

================================================================================
⚙️ ENVIRONMENT VARIABLES
================================================================================

Required:
  DATABASE_URL=postgresql://user:pass@host:port/db

Optional (for better reliability):
  RAPIDAPI_KEY=your_rapidapi_key_here

The app works without RapidAPI key using free fallback APIs.

📖 HOW TO USE THE APP (FOR END USERS)
================================================================================

STEP 1: Get TikTok URL
  1. Open TikTok app or website
  2. Find a video you want to download
  3. Tap "Share" button
  4. Select "Copy Link"

STEP 2: Paste and Download
  1. Open the downloader app
  2. Paste the TikTok URL in the input field
  3. Click "Get Video" button
  4. Wait 2-5 seconds
  5. Click "Download SD" or "Download HD"
  6. Enjoy your watermark-free video!

🐛 TROUBLESHOOTING
================================================================================

Database connection error?
  → sudo service postgresql start

Port 3000 in use?
  → PORT=3001 npm run dev

Module not found?
  → rm -rf node_modules .next && npm install

Video won't download?
  → Check if URL is valid and public
  → Try a different video
  → Add RapidAPI key for better reliability

For more help, see SETUP_GUIDE.md
