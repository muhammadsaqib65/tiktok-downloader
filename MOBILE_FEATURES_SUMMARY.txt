  2. Service worker caches resources
  3. Share target receives shared URLs
  4. App processes URL and downloads video

🔐 PRIVACY & SECURITY
================================================================================

WHAT THE PWA DOES:
  ✅ Caches app files locally
  ✅ Stores user preferences
  ✅ Receives shared URLs

WHAT IT DOESN'T DO:
  ❌ Track users
  ❌ Send data to third parties
  ❌ Access camera/microphone
  ❌ Access contacts
  ❌ Access location

DATA STORAGE:
  • Cache: App files and icons
  • LocalStorage: None (stateless)
  • Cookies: None
  • IndexedDB: None

PERMISSIONS:
  • Internet: Required for downloads
  • Storage: Required for cache
  • Share Target: Optional for sharing

🛠️ TROUBLESHOOTING GUIDE
================================================================================

INSTALL PROMPT DOESN'T SHOW:
  ✓ Check HTTPS is enabled
  ✓ Verify manifest.json is valid
  ✓ Check service worker is registered
  ✓ Test in Chrome/Edge (best support)

SHARE TARGET NOT WORKING:
  ✓ Check manifest share_target config
  ✓ Verify /share route exists
  ✓ Test on Android first (better support)
  ✓ Reinstall the app

SERVICE WORKER ERRORS:
  ✓ Check browser console
  ✓ Verify sw.js is accessible
  ✓ Check HTTPS
  ✓ Clear browser cache

ICONS NOT DISPLAYING:
  ✓ Verify icon files exist in /public
  ✓ Check icon sizes (192 and 512)
  ✓ Ensure PNG format
  ✓ Clear cache and reinstall
