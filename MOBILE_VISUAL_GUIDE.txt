🔄 DATA FLOW DIAGRAM
================================================================================

Share Target Flow
──────────────────────────────────────────────────────────

User in TikTok
      │
      │ Taps Share
      ▼
  TikTok App
      │
      │ Shows share sheet
      ▼
  Share Sheet
      │
      │ User selects TikDL
      ▼
  Operating System
      │
      │ Sends URL to TikDL
      ▼
  TikDL PWA
      │
      ├─► /share endpoint receives URL
      │
      ├─► Redirects to /?url=...
      │
      ├─► Main page loads with URL
      │
      ├─► Auto-fetches video info
      │
      ├─► Displays download buttons
      │
      └─► User downloads video
           │
           ▼
      Downloaded! ✅
