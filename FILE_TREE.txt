🔑 KEY FILES EXPLAINED
================================================================================

📄 src/app/page.tsx
  The main UI you see in the browser
  - Input field for TikTok URL
  - Download buttons
  - Video preview

📄 src/app/api/download/route.ts
  The brain of the app
  - Fetches video from TikTok
  - Removes watermark
  - Saves to database
  - Returns video URLs

📄 src/db/schema.ts
  Database structure
  - Defines 'downloads' table
  - Tracks video downloads

📄 .env
  Secret configuration
  - Database connection URL
  - API keys (optional)

📄 package.json
  Project dependencies
  - Lists all packages
  - Defines scripts

🚀 COMMANDS QUICK REFERENCE
================================================================================

Setup:
  npm install              → Install all dependencies
  npx drizzle-kit push     → Create database tables

Development:
  npm run dev              → Start dev server (localhost:3000)
  npm run typecheck        → Check TypeScript
  npm run build            → Build for production

Production:
  npm start                → Run production server

Database:
  npx drizzle-kit studio   → Open database GUI
  psql $DATABASE_URL       → Connect to PostgreSQL
