================================================================================
💡 COMMON ISSUES
================================================================================

Issue: "No install button anywhere"
Solution:
  - Use Chrome or Edge (not Firefox)
  - Use production URL
  - Wait 10 seconds on page
  - Try menu → Install app

Issue: "Manifest not found"
Solution:
  - Check public/manifest.json in GitHub
  - Redeploy in Vercel
  - Clear browser cache

Issue: "Service worker error"
Solution:
  - Must be HTTPS (Vercel has this ✅)
  - Check sw.js loads
  - Clear cache and retry

Issue: "Works on desktop, not mobile"
Solution:
  - Android: Menu → Install app
  - iPhone: Share → Add to Home Screen
  - iPhone NEVER shows auto-install!
